心创云盘

心创组的共享网盘。活动素材、课程资料和程序产出都放在同一个地方，打开网页就能存取。

仅限成员名单内的手机号访问
  • 把文件或整个文件夹拖进页面就能上传
  • 图片、视频、PDF 和文档直接在线查看，文本可以在线修改
  • 服务器上的程序和 Agent 读写的是同一份文件

这个账号还没有开通云盘

不在成员名单里。可以换一个已开通的账号，或者请心创组管理员把这个手机号加进名单。

暂时读不到网盘状态

可能是网络波动，或者服务正在重启。
